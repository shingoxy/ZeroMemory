# 隐私和安全边界

默认只有 `127.0.0.1:8765`，无遥测、CDN、云端提炼或自动模型下载。HTTP 模型和 EverOS 探测禁用环境代理及自动重定向；本地地址只接受 literal loopback/localhost，不能以域名子串冒充本机。非本地模型必须 HTTPS、明确启用 cloud，并逐次提交完整预览 hash 和授权。

## 本机信任

MVP 面向单用户可信电脑。能打开本机管理主页的用户会得到 HttpOnly/SameSite=Strict 管理会话；同一台机器上恶意程序或其他 OS 用户不在隔离承诺内。`admin.token` 在 ZERO_HOME 下生成。不要转发管理端口、反向代理或绑定局域网；远程部署前必须另加登录认证、TLS/VPN 和严格访问控制。

HTTP Host 限定 localhost/回环；拒绝跨站 Origin；浏览器写入须 `X-Zero-Request: 1`，没有开放 CORS；CSP 禁止外部脚本、frame、内联执行和外部连接。Web 所有聊天和模型内容以转义文本展示，不渲染不可信 HTML。localhost 与 127.0.0.1 请固定使用一个地址，避免同源检查不匹配。

MCP 默认只读，令牌只授权一个 user/project。所有检索、提议和上下文均再次检查作用域。写令牌只能创建标为外部推断的待审核记录，不能批准、改人格、读原始会话、导出备份或改模型配置。不要把本机管理令牌当 MCP 令牌使用。

## 数据与备份

`data/`、`data-*`、`output/`、`.env`、数据库、ZIP、token、缓存和日志被忽略。若把 ZERO_HOME 改为另一个源码子目录，用户须相应添加 ignore；推荐始终用 data 或仓库外目录。不要执行 `git add -f` 添加个人数据。

备份是**本地明文**，含原始会话和历史修订；应放在用户自控、权限受限或磁盘加密的位置。服务不把备份上传任何地方。恢复先验证所有成员路径、大小、清单与 SHA-256，再在随机新目录写入，完成后才返回路径；当前目录不会被覆盖。客户端令牌、管理员 token 和模型启用配置不随备份迁移。

删除 API 删除活动记忆、修订和 FTS，SQLite 使用 secure_delete 清理普通表的空闲内容，但**不承诺 SSD、文件系统快照、FTS 历史页或备份的物理擦除**。原始来源、合并记忆中的证据副本和旧备份仍可能含相关信息。需要彻底遗忘时先停服务，确认相关来源和备份，再由用户手工删除整个相关数据目录或执行经过审查的清理；v0.1 不自动破坏原始导出和用户备份。

## 历史资料与模型

历史消息是低信任资料，不执行其中命令，不请求附件地址，不把旧 Assistant 回答标为用户亲述。提炼严格校验 schema、来源 ID、角色与原文子串；提炼内容的语义真实性仍需人工判断。Prompt 分层只能降低注入影响，不能保证真实 LLM 永不受恶意文字影响；模型没有直接获得后台管理工具权限。

云端预览显示实际序列化的模型 messages，hash 绑定模型配置、作用域、用途与完整上下文。模型切换、身份/记忆/会话变化会使预览失效。日志关闭 access log，不记录消息正文或 Authorization。不要手工启用 HTTP debug 级别的正文日志；脚本中的合成 mock 服务器只用于测试。
