# 公开界面截图

这些图片于 2026-10-30 使用实际 ZeroMemory v0.2.0 Web 界面拍摄，视口为 1440 × 1080。

- `identity.png`：身份卡、人格基线与模拟状态。
- `observatory.png`：记忆星海与筛选控件。
- `goals.png`：目标批准、暂停与人工验收入口。

截图使用独立演示数据库：36 条人工编写的合成记忆（24 条已批准、12 条待审核）、2 个演示目标、1 次本地合成资料读取。演示身份使用工程内置初始身份及头像。

图中没有真实用户聊天、私人记忆、生产库内容或访问令牌。界面中的“真实记忆”指星点直接映射当前数据库记录；此处数据库记录本身是合成演示，不应解读为真实用户事实或实际项目进度。README 已同步标明这一点。

原始验收截图、演示库和运行日志仍保存在被 Git 忽略的 `output/`，不随仓库发布。
