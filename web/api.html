ZeroMemory 本地 API

所有业务接口需要本机管理会话或作用域 Bearer 令牌。浏览器写入还需 X-Zero-Request: 1。默认仅监听回环地址。

完整 OpenAPI JSON schema · 健康状态

主要接口

GET    /v1/identity                       读取身份
PATCH  /v1/identity                       显式授权 + 版本号更新人格
GET    /v1/identity/versions              身份版本
POST   /v1/memories/search                作用域关键词检索
POST   /v1/memories/propose               提议待审核记忆
POST   /v1/memories/{id}/approve          管理员批准
PATCH  /v1/memories/{id}                  生成新待审核版本
POST   /v1/memories/{id}/revoke           撤销
POST   /v1/memories/merge                 人工合并并保留来源
DELETE /v1/memories/{id}                  清理活动记录和索引
POST   /v1/imports                        multipart 上传并预览
POST   /v1/imports/{id}/start             启动 / 断点续跑
GET    /v1/imports/{id}                   查询进度
GET    /v1/messages                       查看本地原文（管理员）
POST   /v1/extractions/quote/{key}        人工引用用户原文为候选
POST   /v1/extractions/preview            预览这一批模型提炼上下文
POST   /v1/extractions/run                模型提炼（无模型时明确等待）
GET    /v1/context                        同一身份与已批准记忆
POST   /v1/chat/preview                   本次完整发送上下文
POST   /v1/chat                           调用配置的模型
POST   /v1/clients                        创建 scoped token（管理员）
POST   /v1/backup                         可读快照与校验清单
POST   /v1/restore                        验证并恢复至新目录

此页面完全本地加载，无外部脚本或 CDN。MCP 接入示例位于项目 docs/MCP_SETUP.md；完整数据模型见 docs/DATA_MODEL.md。
